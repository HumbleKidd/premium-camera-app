# Lumina Ultra Camera

Completely rebuilt premium light-themed camera app with **every major feature** from the feature list simulated or implemented in a single HTML file.

## Live Demo
**https://humblekidd.github.io/premium-camera-app/**

## What's Included (v3.0)
**Basics:** Photo, Video, Front/Rear switch (while recording), Flash, Zoom, Tap-to-focus, HDR, Portrait, Timer, Grid, Gallery.

**Premium:** Pro controls (Exposure, ISO sim, Shutter, WB Kelvin, Grain), RAW sim, Focus Peaking, Zebra, Histogram, Burst, Night, Aspects via modes, Watermark-ready.

**Advanced:** Film/LUT looks, Long exposure style, Astro mode, Intervalometer via timer, Slow-mo note, Dual note, Magic Eraser sim, Best Take sim.

**Standout:** Real-time film grain, Composition Coach overlay, Natural/Zero processing mode, Object ID sim, AR measure sim, DoF readout note, Cinematic aspects, Recipe save note, Voice shutter ready, Private gallery note.

**Plus:** Camera switch while video recording, high-quality JPEG (0.96), MediaRecorder video download, vibrant neon-glass UI.

Permissions requested automatically. Fallback scenic image if denied.
